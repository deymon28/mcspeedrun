# Speedrun 4.0.0 beta (Minecraft 26.3)

The first release for Minecraft 26.3 and the first that runs on Paper, Spigot, and CraftBukkit.
It keeps every gameplay feature of 3.5 and upgrades existing configurations automatically.

## Highlights

- **Paper, Spigot, and CraftBukkit support.** The plugin detects the server software at startup
  and uses the best implementation for it: native text components, asynchronous chunk loading,
  and hidden scoreboard numbers on Paper; the Spigot chat API on Spigot; plain Bukkit elsewhere.
- **Personal bests and splits.** Stage completions are announced with the difference to the best
  split, finished runs are compared with the best time, and `/run records` shows them per game mode.
- **Redesigned browser editor.** Plain-language explanations for every setting, search across all
  sections, a review panel with undo, a stage/task and reward editor, an overview of the server and
  the last upgrade, a built-in guide, dark mode, mobile layout, and 8 interface languages.
- **Safe saving.** Save, apply, and save & apply are separate. Settings that change the rules of a
  running run wait until it ends; startup settings wait for `/run reload` or a restart; concurrent
  edits are detected instead of overwritten.
- **Automatic configuration upgrades.** `config.yml` now records its schema and plugin version. A
  new version rebuilds the file from the current template, transfers every compatible value,
  resets unsupported values, keeps unknown settings, backs up the old file to
  `config-backups/`, and reports every change in the console, in `migration-report.txt`, to
  administrators on join, and in the editor.
- **8 languages** for in-game messages and the editor: English, Ukrainian, German, Spanish,
  French, Portuguese (Brazil), Polish, Simplified Chinese. Customized message files gain new
  messages without losing edits.

## Other improvements

- Administrative commands work from the server console; new `/run help`; tab completion only
  offers commands the sender may use; no duplicate start/pause/reset messages.
- Optional automatic pause while the server is empty (`settings.pause-when-empty`).
- Clickable editor link in game; one-time notices for administrators after installation or an upgrade.
- Language changes apply immediately, including stage and task names.

## Fixes

- Gold highlighting used invisible shulkers that blocked mining the highlighted block; it now uses
  glowing block displays without a hitbox that are never saved with the world.
- On Spigot, structure pre-scans and highlighting ran full block scans on the server thread; all
  platforms now scan snapshots on background threads.
- Village detection scanned up to 270,000 blocks per player every 3 seconds; it now reads the
  block-entity lists of nearby chunks.
- The exit-portal search on Spigot scanned millions of blocks synchronously; it now uses the
  bounded chunk queue and background snapshot scanning on every platform.
- The compass HUD stopped for all remaining players when one player had an unnamed destination.
- Compass state was keyed by player objects (memory leak, lost selection after rejoining).
- The compass menu was detected by its title and compasses by their display name, which broke
  after a language change; both now use proper identifiers.
- Player scaling on quit counted the leaving player.
- `/run status` reported "Running" when no run was active.
- Run and trace logs flushed every line on the server thread; they are now written in the background.
- Hidden compass lodestones in unloaded chunks and location beams could stay in the world after a
  reset, `/run stop`, or a server shutdown; they are now always removed.
- Exit-portal searches of two players at the same time cancelled each other.

## Security

- The editor key is passed in the URL fragment and the `X-Speedrun-Token` header only, so it never
  appears in request logs or referrers. Query-string tokens are no longer accepted.
- Host-header validation against DNS rebinding, throttling of wrong keys, a strict
  Content-Security-Policy and related headers, and a whitelist for static files.
- Console command rewards can no longer be added through the editor (configurable in `config.yml`).
- `config.yml` is written atomically, keeps its file permissions, and is never replaced when it
  contains invalid YAML. A damaged `records.yml` is renamed instead of being overwritten.
- Requests without a key cannot trigger the wrong-key throttle, so other web pages cannot lock an
  administrator out of the editor.

## Compatibility and upgrade

- Requires Java 25. Built against Spigot API 26.3 and Paper API 26.3 (Paper 26.3 is a beta build).
- Upgrade: stop the server, replace the jar, start the server. Your previous `config.yml` is kept in
  `plugins/Speedrun/config-backups/`.
- The configuration format stays compatible: all 3.5 settings keep their names.
- Folia is not supported.

## Verification

- 82 JUnit tests and 6 browser-editor state tests pass, including an upgrade of the 3.5.4 default
  configuration.
- Real-server smoke tests (25 runs, all passed) on Paper 26.3 build 157, Spigot 26.3, and
  CraftBukkit 26.3 for the NORMAL, CASUAL (SAFE/BALANCED/AGGRESSIVE/LOCATE), HARDCORE, and
  upgrade-from-3.5.4 profiles, plus Paper 26.1.2 build 69 (NORMAL, CASUAL, HARDCORE, upgrade):
  startup, platform detection, console run lifecycle commands, authenticated and unauthenticated
  web API, translations, and graceful shutdown.
- An independent code review of security and threading; its findings are fixed in this release.
- Manual browser check of the editor (save, apply, deferred apply during a run, conflict detection,
  rejected console rewards, mobile layout).
- Not covered by automated tests: multiplayer gameplay with real clients and long-running load.
  Please report issues with a trace file (`diagnostics.trace.enabled`).
